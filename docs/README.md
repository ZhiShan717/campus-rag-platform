# 项目文档导航

文档按使用场景归类。每类信息在对应文档维护，避免在多个文件中重复更新。

## 阅读顺序

新队员从[队员信息速查](team/队员信息速查.md)了解仓库与现状，再按[团队协作与接入](team/团队协作与接入.md)准备本机环境。开始业务开发前，阅读[目录与开发约定](development/项目目录与开发约定.md)，再与相关成员对齐接口和架构。

需要逐步的软件安装、仓库克隆、路径适配、服务和模型检查说明时，使用[详细安装与配置指南 PDF](../output/pdf/校园RAG平台_详细安装与配置指南.pdf)，对应的[可编辑正文](team/详细安装与配置指南.md)随仓库维护。

## 按任务查找

| 要做的事 | 资料 |
| --- | --- |

| 按步骤安装与配置，或下载离线指南 | [详细指南 PDF](../output/pdf/校园RAG平台_详细安装与配置指南.pdf) / [可编辑正文](team/详细安装与配置指南.md) |

| 查目录位置、文件归属和开发规范 | [development/项目目录与开发约定](development/项目目录与开发约定.md)：统一目录说明与维护规则 |

项目总入口为根目录 [README.md](../README.md)。源码职责以各模块 README 为准；密码、模型、个人授权和本机检查日志不放入本目录。

新增文档后在此补充导航；新建或移动源码目录时同步根 README 和对应模块 README。接口与架构目录目前仅有说明，业务契约和设计仍需团队落实。
