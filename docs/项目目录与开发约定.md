# 项目目录与开发约定

建立与整理日期：2026-10-23。项目采用一个仓库管理 Java 平台、Python RAG 运行时和 Vue 前端，各模块在同一仓库内协作。项目源码与环境配置分开：业务目录保留在根目录，开发环境统一在 `environment/`。

## 顶层结构

```text
campus-rag-platform/
├── pom.xml                    Java 17 聚合 POM
├── gateway-service/           网关、认证入口与路由
├── auth-service/              用户、角色与权限
├── doc-service/               文档、版本与处理任务
├── search-service/            检索服务与 Java/Python 检索协作
├── admin-service/             管理功能
├── eval-service/              评测任务与结果
├── rag-runtime/               Python RAG 与 Agent 运行时
│   ├── src/                   后续 API 与应用入口
│   ├── graph/                 LangGraph 编排
│   ├── mcp_server/            MCP 工具
│   ├── rag/                   索引、检索、重排与生成
│   ├── guardrails/            输入输出检查与拒答策略
│   ├── eval/                  RAG 评测逻辑
│   ├── config/                配置约定
│   └── tests/                 Python 模块测试
├── frontend/                  Vue 3 + Vite + TypeScript 目录
│   ├── public/                静态资源
│   ├── src/                   页面、组件、状态与 API 调用
│   └── tests/                 前端模块测试
├── database/
│   ├── mysql/migrations/      版本化结构变更
│   ├── mysql/seeds/           开发样例数据
│   └── elasticsearch/index-templates/
├── deploy/
│   ├── docker/                后续业务容器构建
│   ├── nginx/                 后续反向代理
│   └── k8s/                   后续 Kubernetes 清单
├── tests/                     跨模块 integration、e2e、fixtures
├── docs/                      团队说明、api、architecture
├── environment/               开发环境配置，与业务目录分开
│   ├── 启动*.cmd 等           日常启动、停止、检查与登录辅助入口
│   ├── 校园RAG开发环境.code-workspace
│   ├── *.ps1、*.py            工具、依赖、基础服务与模型管理
│   ├── docker-compose.yml     开发中间件，附属配置另见子目录
│   ├── requirements-*         Python SDK 与模型依赖锁
│   └── docs/                  原始环境安装手册
├── .local/                    本机工具、模型与服务数据，Git 排除
├── .venv/                     本机 Python 虚拟环境，Git 排除
└── .setup/                    本机运行状态、日志与检查记录，Git 排除
```

Git 不保存空目录，因此尚无实现的目录使用 `.gitkeep` 保留；加入真实文件后可以删除对应占位文件。

`environment/` 中的脚本、Compose、依赖清单与手册随 Git 分享；实际 `.env`、`.env.application` 由成员本机生成并被排除。根目录 `.local/`、`.venv/`、`.setup/` 是独立本机运行区，继续保留现有路径。环境操作入口见[环境说明](../environment/README.md)，文件分类见[文件夹说明](文件夹说明.md)。

## Java 模块

六个模块都采用 Maven 标准结构：`src/main/java/`、`src/main/resources/`、`src/test/java/`。Java 包统一以 `cn.campus.rag` 开头，各模块细分自己的子包。

根 POM 管理 Java 17 和六个子模块。开发终端在仓库根目录可运行：

```powershell
mvn -o -B validate
```

该命令校验模块配置。当前没有 Spring 启动类、控制器或业务依赖，校验通过不代表服务可以运行。Spring Boot、Spring Cloud 和 Alibaba 依赖组合应先统一，再写入根 POM；不沿用手册中尚未匹配的版本组合。

## 协作方式

按 [团队协作与接入](团队协作与接入.md)加入私有仓库。在任务分支中修改所负责模块，跨模块字段与配置通过接口文档或设计记录同步，经 Pull Request 审查后合并。

目录已经建立；成员分工、业务实现、框架初始化、表结构、接口契约与业务验收仍需逐项推进。目录中的说明是职责划分，不能视为对应功能已经实现。
