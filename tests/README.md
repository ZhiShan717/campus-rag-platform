# 跨模块验证

| 目录 | 用途 |
| --- | --- |
| `integration/` | Java、Python 与中间件间的接口及链路验证 |
| `e2e/` | 用户操作、问答与引用展示等端到端验证 |
| `fixtures/` | 可共享的人工构造文档与测试数据 |

当前仅建立目录，尚无业务用例或测试框架。各模块单元测试放在自己的测试目录；跨模块接口稳定后再加入这里的验证。

既有环境和模型验证仍使用 [dev-environment](../dev-environment/README.md) 中的检查入口。将来加入 fixtures 时使用可公开给项目成员的人工构造材料，不提交真实学生数据、账号或本机凭据。
