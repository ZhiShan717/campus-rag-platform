# 前端目录

计划使用 Vue 3 + Vite + TypeScript，承载校园知识库问答、文档管理、后台管理与评测页面。

当前仅完成目录与职责划分，尚未初始化前端工程；没有 `package.json`、依赖锁文件或可运行页面，**当前不能执行 `npm run dev`**。

## 目录职责

```text
frontend/
├── public/                 # 原样发布的公共静态资源
├── src/
│   ├── api/                # 网关请求封装与按业务划分的接口调用
│   ├── assets/             # 由前端构建工具处理的图片、样式、字体等资源
│   ├── components/         # 多个页面复用的界面组件
│   ├── composables/        # 可复用的 Vue 组合式逻辑
│   ├── layouts/            # 页面框架与导航布局
│   ├── router/             # 路由与页面访问控制
│   ├── stores/             # 跨页面共享状态；具体状态库待初始化时统一
│   ├── types/              # 共享 TypeScript 类型与接口数据类型
│   ├── utils/              # 与界面无关的通用工具
│   └── views/
│       ├── qa/             # 问答、历史会话与引用展示
│       ├── documents/      # 知识库文档上传、列表与处理状态
│       ├── admin/          # 用户、角色与知识库管理
│       └── evaluation/     # 问答质量评测与结果查看
└── tests/
    ├── unit/               # 单元与组件测试
    └── e2e/                # 用户操作流程测试
```

空目录用 `.gitkeep` 保留，添加实际文件后可删除对应占位文件。目录中的页面名称仅划分开发位置，不表示页面或功能已经实现。

## 首次开发

1. 团队先统一 Vue、Vite、TypeScript、路由、状态管理与测试工具的版本，再在本目录初始化工程，提交真实的 `package.json` 和统一包管理器的锁文件。初始化时保留本目录说明和已划分的业务目录。
2. 使用锁文件安装依赖，并以最终 `package.json` 中定义的脚本为准运行和构建。负责人当前工具版本记录在[团队协作与接入](../docs/team/团队协作与接入.md)；工具已安装不代表前端依赖已经初始化。
3. 与网关负责人确认登录方式、权限、请求路径、响应结构、错误格式，以及流式问答与引用数据契约后，再编写 `src/api/` 和相应页面。具体接口、业务端口及前端访问地址尚未确定。
4. 根据实际采用的工具补充最小运行检查与关键页面测试，将可公开的配置项放入示例文件，并同步更新本说明。

## 接入边界

- 浏览器通过网关访问后端业务接口；网关路径与开发代理配置在接口契约确定后填写。
- 前端不直连 MySQL，也不持有 MinIO 管理员凭据。文档上传与下载方式由后端接口和权限契约确定。
- 前端构建变量会进入浏览器产物，只能保存可公开的地址和开关。数据库密码、对象存储密钥、LLM Key、个人登录令牌不得放入前端代码或构建变量。
- 组件共享交互，`views/` 组织业务页面；请求逻辑集中在 `api/`，避免各页面分别定义相互冲突的接口与数据格式。
